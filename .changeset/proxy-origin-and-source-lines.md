URL mode works behind a reverse proxy that terminates TLS: the relay keys the page by the browser's own origin, checks `Origin` against the dev server's trusted hosts and forwarded headers, and logs why it refused a request. `intervu <https url>` accepts a dev certificate from a local CA and checks that the plugin sees the Session it opened. A Feedback whose page snapshot a proxy refuses still delivers the note, and the panel shows why a send failed. The snapshot drops scripts, styles, inline SVG paths and `data:` payloads. Annotation sources name the line as written when the React Compiler rewrites a component, and a click inside a third-party component names the app's call of that component.
