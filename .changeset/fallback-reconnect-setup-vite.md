The last three sandbox frictions die. When the resolved state dir is not writable (a sandboxed `~/.local/state`), intervu falls back to `$TMPDIR/intervu-<user>` and says so, and `intervu status` names the state dir in use. A `poll` whose connection drops without a decoded response re-issues itself silently against the same handle, preserving any remaining `--timeout` budget, and fails with a structured error only when the daemon stops answering `/health` - no more hand-rolled `--timeout 240` loops. And `intervu setup vite` writes the bundled dependency-free ESM plugin to `<project>/.intervu/vite.mjs` with no package manager and no network, printing the exact import line and config edit; it is idempotent and never edits `vite.config.ts` itself.
